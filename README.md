# Maze Solver

> 📚 **Learning project** — built while following the [boot.dev](https://boot.dev) back-end path. Kept as a record of my progress; not actively maintained.

Generates a random maze with a Tkinter window and solves it visually with recursive depth-first search.

**Stack:** Python, Tkinter, `unittest`

## Run it

```bash
python3 main.py
```
